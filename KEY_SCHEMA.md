# STRONG · RU – KEY_SCHEMA

Формат данных колоды. Описывает файлы как они есть, а не как задумывались.

---

## 0) Термины

- **key** – номер словаря Стронга с префиксом: `H####` (иврит, 1–8674) или `G####` (греческий, 1–5624). Без ведущих нулей.
- **canon** – «канон»: 3–7 слов через ` · `, максимально прямо.
- **human_echoes** – «частые человеческие отклики»: 3–7 глаголов или образов через ` · `.
- **prompt** – один вопрос, который запускает самонаблюдение. Начинается с `❓`.
- **refs** – стихи, где стоит это слово. Не тематическая подборка, а употребления именно этой леммы.
- **replaces** – прежний ключ карточки до ревизии 2026-10. Служебное поле.
- **added** – карточка добавлена при ревизии, в первой публикации её не было.

---

## 1) Файл

Один файл – одна сфера – 30 ключей. Файл – JSON-объект, ключи которого – номера Стронга, значения – карточки.

```json
{
  "H982": {
    "canon": "доверие · надёжность · опора",
    "human_echoes": "положиться · перестать проверять",
    "prompt": "❓ Кому ты можешь доверять, не проверяя?",
    "refs": [
      {
        "ref_mt": "Пс 37:3",
        "ref_synodal": "Пс 36:3",
        "word": "בְּטַ֣ח",
        "gloss_en": "trust",
        "occurrences": 117
      }
    ],
    "replaces": "H2001"
  }
}
```

### Поля карточки

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `canon` | string | да | канон |
| `human_echoes` | string | да | отклики |
| `prompt` | string | да | вопрос |
| `refs` | array | да | минимум один стих |
| `replaces` | string | нет | прежний ключ |
| `added` | boolean | нет | `true`, если карточка новая |

### Поля `refs[]`

| Поле | Описание |
|---|---|
| `ref_mt` | книга, глава, стих по масоретскому тексту |
| `ref_synodal` | то же по Синодальному переводу |
| `word` | еврейское слово в этом стихе, с огласовками, как в тексте |
| `gloss_en` | подстрочный перевод этого слова из размеченного текста |
| `occurrences` | число вхождений леммы во всём Танахе |

---

## 2) Нумерация стихов

- Основная – масоретская (`ref_mt`).
- Синодальный перевод в Псалтири следует Септуагинте: для Пс 10–147 номер псалма на единицу меньше масоретского (есть исключения в 114–116 и 147). Номер стиха внутри псалма совпадает: надписание считается стихом 1 в обеих нумерациях.
- В остальных книгах различия единичны, они учтены в `ref_synodal`.

---

## 3) Правила отбора ключа

1. Ключ существует в словаре Стронга и в указанном диапазоне.
2. У леммы есть хотя бы одно вхождение в размеченном тексте Танаха; у ключа в `refs` – стих, где стоит именно она.
3. Значение канона лежит в поле значений леммы по Стронгу и по словоупотреблению. Если канон требует значения, которого у слова нет, меняется ключ, а не значение.
4. Ключом не становятся:
   - имена людей, городов, народов;
   - служебные слова (предлоги, союзы), кроме случаев, когда канон о них;
   - номера вне диапазона;
   - номера, у которых нет вхождений в размеченном тексте (пример: `H3212` слит с `H1980`).
5. Один ключ может стоять в нескольких сферах, если канон в каждой держится на одном и том же значении леммы.
6. Омонимы под одним номером Стронга (размеченный текст разводит их суффиксами `A`, `B`) проверяются по стиху: `refs` указывает на нужный омоним.

---

## 4) Проверка файла

Перед коммитом:

- 30 карточек в файле, ключи уникальны;
- все ключи в диапазоне и без ведущих нулей;
- у каждой карточки `canon`, `human_echoes`, `prompt`, `refs` непустые;
- каждый `refs[].ref_mt` реально содержит лемму ключа.
